OFL 1.1 condition 2 permits the fonts to be "bundled, redistributed and/or sold
with any software, provided that each copy contains the above copyright notice
and this license". This file is that copy. It sits beside the font files in both
games' custom-asset trees and is packed into soh.o2r and 2ship.o2r with them by
this repository's custom-asset step, so the notice travels with the fonts in a
distributed build as well as in the source tree.

Condition 3 is the one to read before renaming anything: a Reserved Font Name
below may not be used by a Modified Version of that font without the copyright
holder's written permission.

THE TWO COPIES OF THIS FILE ARE BYTE-IDENTICAL ON PURPOSE. Do not "tidy" either
one to list only the fonts in its own directory. Both custom-asset archives are
mounted into a single libultraship ArchiveManager in a single-executable build,
where resolution is last-added-wins, so a path carried by both archives with
different bytes resolves differently depending on which game booted first. That
is issue #595, and src/common/tests/test_curated_archive_order.c fails on it.
One notice covering the whole shipped set is what keeps `fonts/OFL.txt`
order-independent. The "carried in" column below is how the per-tree difference
is recorded instead.

    Copyright Dave Gandy 2016. All rights reserved.

    Font Awesome 4 is the icon face every RedShipBlueShip window draws its
    glyphs from, and it does not ship as a file: it is base85-compressed into
    libultraship/include/ship/window/gui/Fonts.h ("File:
    'fontawesome-webfont.ttf' (165548 bytes)") and pushed into the ImGui atlas
    at startup, so it is compiled into the redship binary. Its own `name` table

    LESS and Sass files, which this project does not use, are MIT). The
    "All rights reserved" wording above is that font's own name-ID-0 string and
    is reproduced because the OFL requires the notice to travel unaltered - it
    is not a claim that the face is ungranted. Upstream:
    https://github.com/FortAwesome/Font-Awesome (4.x).
    The C++ icon-name header beside it,
    libultraship/include/ship/window/gui/IconsFontAwesome4.h, is generated by
    https://github.com/juliettef/IconFontCppHeaders from that upstream's
    src/icons.yml; see THIRD_PARTY_NOTICES.md.
